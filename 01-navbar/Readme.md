# 📱 Responsive Navbar

A clean and responsive navbar built with **HTML, CSS, JavaScript, and GSAP**. The project includes a desktop navigation, a mobile hamburger menu, and a simple GSAP timeline animation for a smooth page entrance.

## 📂 Folder Structure

```text
01-navbar/
├── index.html
├── styles.css
├── script.js
└── README.md 
```

## 🚀 How It Works

### `index.html`
Contains the navbar, hero section, and imports the CSS, JavaScript, and GSAP CDN.

### `styles.css`
Handles the responsive layout, desktop and mobile navigation styles, and the hamburger menu.

### `script.js`
- Toggles the mobile navigation when the hamburger button is clicked.
- Uses a GSAP timeline to animate:
  - Navbar
  - Logo
  - Menu button
  - Navigation links
  - Hero section

## 🛠️ Technologies
