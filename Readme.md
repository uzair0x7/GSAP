A collection of **modern GSAP animation examples** organized into folders. This repository serves as my personal library of reusable animations, effects, and experiments built with **HTML, CSS, JavaScript, React, and GSAP**.

Whether you're learning GSAP, building modern landing pages, or looking for inspiration, feel free to explore the examples.

## 🛠️ Getting Started

Clone the repository:

```bash
git clone https://github.com/uzair0x7/GSAP.git
```

Open any HTML project directly in your browser.

For React projects:

```bash
npm install
npm run dev
```

or

```bash
npm start
```

depending on the project setup.

---

## 📦 Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- React
- GSAP
- ScrollTrigger

Include GSAP using the CDN:

```html
<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
```

For ScrollTrigger:

```html
<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/ScrollTrigger.min.js"></script>
```

```javascript
gsap.registerPlugin(ScrollTrigger);
```
