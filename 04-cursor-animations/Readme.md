# 🖱️ Custom Cursor Animation

A modern custom cursor animation built with **HTML, CSS, JavaScript, and GSAP**. The cursor smoothly follows the mouse, changes its appearance when hovering over an image, displays contextual text, and allows the image to be zoomed with a click.

## 📂 Folder Structure

```text
04-custom-cursor/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## 🚀 How It Works

### `index.html`

Contains the custom cursor, image container, overlay, and image element.

### `styles.css`

Creates a fullscreen layout, styles the custom cursor, centers the image, and provides the dark theme.

### `script.js`

The animation includes:

- Smooth custom cursor movement using GSAP.
- Cursor scaling on image hover.
- Dynamic cursor labels (**View**, **Zoom**, **Close**).
- Click-to-zoom image animation.
- Click outside the image to restore the original scale.
