# 📜 GSAP ScrollTrigger Demo

A multi-section landing page demonstrating **GSAP** and **ScrollTrigger** animations. This project showcases entrance animations, pinned sections, horizontal text movement, staggered cards, and scroll-driven effects.

## 📂 Folder Structure

```text
02-scrollTrigger/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## 🚀 How It Works

### `index.html`
Contains four full-screen sections:

- **Page 1** – Hero section
- **Page 2** – Services cards
- **Page 3** – About section
- **Page 4** – Contact section

It also imports the **GSAP** and **ScrollTrigger** CDNs.

### `styles.css`
Defines the page layouts, typography, cards, responsive design, and section styling.

### `script.js`

The animations include:

- Hero title and subtitle entrance animations
- Hero buttons scaling on scroll
- Pinned sections using ScrollTrigger
- Horizontal scrolling text effects
- Staggered card reveal animations
- About section fade and slide animations
- Final section text scaling and content reveal
